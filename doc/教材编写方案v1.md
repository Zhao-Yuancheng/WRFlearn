## 1. 一句话定位

一本以盛裴轩《大气物理学》（第 2 版）前 6 章知识主线为骨架、以 WRF（v4.8.0）/WPS（v4.7.0）源码与实操为“第二主线”的本科教材：**每一节物理都回答三个问题——书上怎么讲、老师怎么考、模式里怎么算**。

## 2. 目标与读者

| 项 | 设定 |
|---|---|
| 主要读者 | 兰大大气科学学院本科生（作者本人为主用户）：正在修《大气物理学》，具备 Fortran/C/Python/Linux 基础，有 centos7 + singularity + oneapi 集群，可编译 AVX-512 的 WRF 4.8.0 / WPS 4.7.0 |
| 核心目标 | ①课程考试（前 6 章，闭卷 70%）；②建立“物理概念 ↔ 数值模式实现”的双向映射；③为大三动力学与后续科研（WRF 下垫面/城市热环境方向）铺路 |
| 非目标 | 不替代原书完整推导体系；不写成 WRF 用户手册；不涉及 WRF-Chem 深度内容（仅引用） |

```

├─ ch04_大气的分层和结构.md

├─ ch06_大气热力学基础.md
├─ ch07_展望_从大气物理到大气动力学.md   （短文：衔接第7章/大三课程，浅读 solve_em）
```

章号与书号一致，便于对照；各章内部按书小节展开（如 ch03 内含 3.1–3.5）。

### 4.2 每章统一模板（八段式）

1. **本章地图**：书结构图 + PPT 考点清单 + WRF 锚点总表（一屏速览）
2. **物理精讲**：按书小节展开；概念—公式—推导—物理图像；公式用 LaTeX；关键推导完整给，次要推导给思路并标注书页
3. **考点透视**：从 PPT 提取的“重点/掌握要点/思考题”逐条展开，配例题（含书后习题选用，答案可对书末“部分习题答案”）
4. **WRF 中的对应**：源码走读（文件、子程序、变量、Registry、namelist）；先讲“模式为什么这样近似物理”，再读代码；引用一律 `文件路径 + 子程序名`
5. **动手实验**：每章 1–2 个（见 §6 两轨制）
6. **思考题与习题**：书习题精选 + 模式视角补充题
7. **延伸阅读**：指向书第 7–20 章相关节、WRF 文档、经典论文
8. **术语速查**：本章中英对照

## 5. 编写规范

### 5.1 事实核验协议（硬约束）

1. **版本**：一切版本特性陈述以 `source\` 内源码为准；涉及官方口径时检索 UCAR/MMM 文档与 GitHub release notes，并在页脚标注来源与日期
2. **源码引用**：只引用“文件相对路径 + 子程序/变量名”，**不写行号**（防漂移）；引用代码必须当时用 Read/Grep 看过原文，禁止凭记忆转述
3. **书引用**：标注印刷页码与图号（正文页 N → `book\page_{N+14}.jpg`），关键图可在教材目录内复制一份小图（若版权策略允许，见提问清单）
4. **不确定即标记**：写作中无法当场核实的陈述打 `[TODO-verify: 问题]`，每章交付前清零或降级为“存疑说明”
5. **核验留痕**：每次查证记入 `workspace\context\verify_log.md`（文件:符号 + 一句话结论），供后续章节复用，避免重复劳动

### 5.2 公式、图表与排版

- 公式：Markdown + LaTeX（`$...$`/`$$...$$`），编号沿用书式（如 式(2.2.9a)），便于对照原书
- 图：书图按“页码提取图”引用；PPT 图可从 `ppt\*_unpack\ppt\media\` 取；自绘示意图用 matplotlib/drawio 生成（存 `doc\assets\`）——版权口径见提问清单
- 代码块：`fortran`/`python`/`bash` 语言标注；WRF 代码片段 ≤30 行，只截关键段
- 用全角引号；中英术语首次出现给英文原文

### 5.3 考点标注

PPT 明确标注的“重点/掌握要点/思考题”在正文用统一记号 `【考点】` 段落呈现，并归入每章“考点透视”一节；模拟题风格对齐闭卷笔试。

## 6. 实验设计（两轨制）

| 轨 | 环境 | 内容 | 依赖 |
|---|---|---|---|
| 轻轨（每章必有） | 本地 Python（建议 P312 环境装 metpy/numpy/matplotlib/netCDF4/xarray） | 公式复现、画图（普朗克曲线、T-lnP、垂直廓线）、小数据计算 | 已具备；装包见提问清单 |
| 重轨（选做，随集群条件） | centos7 集群 + singularity + oneapi 的 WRF/WPS | WPS→real→wrf 全流程个例；namelist 敏感性实验（辐射方案、radt、垂直分层等） | 需要用户提供：调度系统/队列、已编译 WRF 路径、测试数据（见提问清单） |

轻轨实验不依赖集群，保证教材任何章节都能“当天动手”；重轨实验以附录 B 汇总为完整工作流。

## 7. 上下文管理方案（写作工程）

### 7.1 状态文件与目录纪律

```
workspace\context\notes.md      追加式：目标/验收/决策/失败尝试/下一步（每任务必更新）
workspace\context\progress.md   当前状态快照（可重写）
workspace\context\verify_log.md 源码/文档查证留痕（追加式）
workspace\outline\chapter_map.md 章—源码对照图（随写作进度增补“已核验”标记）
workspace\ppt_text\*.md         PPT 考点文本（已完成，只读复用）
workspace\book_manifest.csv     书页索引
```

临时文件、脚本、日志一律入 `workspace\`；交付只入 `doc\`。书 PDF、`.nc/.tar` 等不可重建文件永不删除、永不覆盖。

### 7.2 每章任务流程（handoff 协议）

1. **开章**：新会话，首条消息自报：读 `notes.md` + `progress.md` + `chapter_map.md` 对应章段落；明确本章验收标准（考点覆盖齐、`[TODO-verify]` 清零、实验可运行）
2. **写作中**：按需局部读源码（Grep 定位 → Read 行段）与书页（读指定页图），不做全库漫游；PPT 公式按“讲+页码”读图
3. **收章**：更新 `chapter_map.md`（该章锚点标“已核验”）、`verify_log.md`、`notes.md`（决策+失败尝试）、`progress.md`；交付 `doc\chXX_*.md`
4. **跨章**：每章一个会话，不 carry 上一章原始素材；需要复用的事实一律沉淀到上述状态文件，而非聊天记录

### 7.3 上下文预算红线

- 单次不整读：`Registry.EM_COMMON`（数千行）、微物理方案源文件（数千行）、RRTMG 源文件——只 Grep+局部 Read
- 书页图一次只读当前需要的 1–3 页
- PPT 文本已离线化，不再解包重读
- 超过 5 个文件的新一轮探索 → 先写 notes 再继续或拆任务
